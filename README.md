# AutoBuddy AI 🚗

A RAG-based automotive troubleshooting assistant using LLM reasoning.

## Overview

AutoBuddy AI helps diagnose vehicle problems by retrieving automotive knowledge and generating explainable troubleshooting suggestions.

## Current Features

- Automotive knowledge base
- Text embeddings
- FAISS vector search
- Streamlit interface

## Tech Stack

- Python
- LangChain
- FAISS
- Sentence Transformers
- Streamlit
